# Flash SIPS — Public Landing Platform

The official public-facing marketing and institutional showcase website for the **Skill Intelligence Placement System (SIPS)** by Flash Innovations.

## Features
- **Product-Led Telemetry & Decks**: Comprehensive 5-stage placement architecture showcase.
- **Institutional Briefing Request**: Inbound pilot registration form sending leads directly to Super Admin.
- **Subdomain Portal Routing**: Navigation links directing students, placement officers, and admins to their respective web portals.
- **Ultra-Fast & SEO-Optimized**: Zero dashboard bundle overhead, sub-second load times, and clean semantic metadata.

## Development

```bash
npm install
npm run dev
```

The dev server runs on `http://localhost:5176`.

## Production Build
